## 檢查器調整紀錄

初次執行的錨點檢查器只收集 HTML `<a id>`，因此把 `references.md` 的 Markdown 標題 `### SRC-001` 至 `### SRC-004` 誤報為缺少錨點。檢視檔案後確認連結本身正確，隨即修正檢查器，加入 Markdown 標題 slug，再於本次 Run 01 內重跑並通過。這是形成 Lint 結論前修正的驗證工具問題，沒有把它記成 Wiki 內容失敗。
